Adaptive runtime-based DDoS mitigation system deployed on production infrastructure. Ironwatch provides real-time threat detection and automated response to protect critical services from distributed denial-of-service attacks.

Implemented using Rust for performance-critical network monitoring with integration to AbuseIPDB for IP reputation intelligence.

### Key Capabilities

- **Anomaly Detection**: Detects abnormal traffic spikes using threshold-based monitoring and pattern analysis
- **Attack Attribution**: Identifies high-frequency source IPs contributing to service overload
- **Threat Intelligence**: Leverages AbuseIPDB reputation data to evaluate and score malicious IP addresses
- **Dynamic Mitigation**: Automatically enforces blocking rules to mitigate ongoing attacks in real-time
- **Proven Results**: Reduced attack traffic by approximately 80% in production deployment
