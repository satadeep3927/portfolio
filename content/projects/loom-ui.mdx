Monitoring and observability dashboard for Loom workflow execution. Provides comprehensive visibility into workflow orchestration with real-time execution tracking, state visualization, and health monitoring.

Built with TypeScript and modern frontend architecture, Loom-UI transforms event-sourced workflow data into actionable insights for system operators and engineers.

### Key Capabilities

- **Execution Visualization**: Visualizes workflow execution graphs with complete state transitions and event history
- **Runtime Monitoring**: Displays execution state, runtime events, and workflow health metrics in real-time
- **System Observability**: Monitor workflow health, identify bottlenecks, and track failure patterns
- **Search & Discovery**: Advanced filtering and search capabilities for rapid workflow identification
- **Type-Safe Architecture**: Strongly-typed TypeScript components ensure reliability and maintainability
