Workflow orchestration engine designed for deterministic execution of long-running processes. Loom implements event-sourced workflow execution with deterministic replay, enabling fault-tolerant orchestration of asynchronous tasks in distributed systems.

Inspired by systems like Temporal and the Durable Task Framework, Loom makes long-running business processes reliable, observable, and easy to reason about through event-sourced state management.

### Key Capabilities

- **Event-Sourced Execution**: Implements event-sourced workflow execution and deterministic replay for complete state reconstruction
- **Fault Tolerance**: Supports fault-tolerant workflow execution with automatic state reconstruction from event logs
- **Distributed Systems**: Designed for distributed systems requiring reliable orchestration of asynchronous tasks
- **Deterministic Replay**: Workflows can survive restarts, failures, and deployments without losing progress
- **Production Ready**: Python-first API with pluggable persistence layer for enterprise deployment
