Infrastructure monitoring system for ATXFloods critical emergency response platform. Provides real-time observability, health checks, and performance monitoring for flood monitoring infrastructure requiring high availability.

Built with Next.js and Node.js to ensure continuous operational reliability of public safety systems.

### Key Capabilities

- **Real-Time Analytics**: Live dashboards providing instant visibility into system health and performance metrics
- **Automated Alerting**: Intelligent alert system with configurable thresholds for critical events and anomalies
- **Performance Tracking**: Continuous monitoring of application metrics, API response times, and resource utilization
- **High Availability**: Ensures operational reliability of critical flood monitoring infrastructure
- **System Observability**: Comprehensive logging and tracing for rapid incident diagnosis and resolution
- **Emergency Response Optimization**: Enhanced system responsiveness for time-critical public safety operations
