LLM-powered database system that combines SQLite with large language model capabilities, enabling both SQL and natural language queries. Built with high-performance gRPC protocol and Knex.js-inspired client SDKs for Rust, Python, and JavaScript/TypeScript.

Designed for production workloads requiring intuitive natural language interfaces alongside traditional SQL querying with multi-tenant architecture and JWT-based authentication.

### Key Capabilities

- **Dual Query Modes**: Execute raw SQL or use natural language queries converted to SQL via LLM integration with OpenAI API
- **gRPC Protocol**: High-performance binary protocol with Protocol Buffers for efficient client-server communication on HTTP/2
- **Multi-language SDKs**: Knex.js-inspired client libraries for Rust, Python, and JavaScript/TypeScript with fluent query builder interfaces
- **Multi-tenant Architecture**: Namespace isolation with JWT-based authentication and user-specific access control
- **Full SQLite Support**: Complete DDL/DML/DQL capabilities including CTEs, window functions, JSON operations, triggers, and full-text search
- **Production Ready**: Thread-safe connection management, interactive CLI, database schema introspection, and comprehensive error handling
