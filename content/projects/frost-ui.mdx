Developer tooling for React Native component management inspired by shadcn/ui. FrostUI CLI streamlines component installation, dependency management, and asset configuration for React Native and Expo projects.

Published to NPM with complete authentication, registry management, and theming capabilities for enterprise mobile development workflows.

### Key Capabilities

- **Secure Component Access**: GitLab-based authentication for private component registries and organizational repositories
- **Automated Installation**: Single-command component installation with automatic dependency resolution
- **Component Discovery**: Search and browse component registry by name, description, and metadata
- **Theming Infrastructure**: Built-in theming system with runtime theme switching and style management
- **Platform Intelligence**: Auto-detects React Native vs Expo projects and adjusts configuration accordingly
- **Asset Pipeline**: Automatic font linking and asset management reducing manual configuration overhead
- **Registry System**: Centralized component registry ensuring UI consistency across organizational projects
