Open-source music streaming application built with Flutter for cross-platform mobile deployment. Provides personalized music discovery, playlist management, and offline playback capabilities.

Full-stack implementation with Flutter frontend and Node.js/TypeScript backend deployed on Heroku cloud infrastructure.

### Key Capabilities

- **Cross-Platform Mobile**: Flutter-based implementation supporting iOS and Android from single codebase
- **Music Discovery**: Browse extensive music library across multiple genres with intelligent categorization
- **Playlist Management**: Create, organize, and share custom playlists with track curation tools
- **Personalization Engine**: Machine learning-driven recommendations based on listening history and preferences
- **Offline Playback**: Download tracks for offline listening with synchronized state management
- **Search & Discovery**: Full-text search across songs, artists, and albums with instant results
- **Social Features**: User profiles and social following for music activity sharing
- **Adaptive UI**: Dark mode and responsive design optimized for various screen sizes
